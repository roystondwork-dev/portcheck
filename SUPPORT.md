# Getting help

- **Documentation:** <https://roystondwork-dev.github.io/portcheck/>; also `portcheck --help` and `portcheck <command> --help`.
- **Questions & ideas:** [GitHub Discussions](https://github.com/roystondwork-dev/portcheck/discussions).
- **Bugs:** [open an issue](https://github.com/roystondwork-dev/portcheck/issues/new/choose) with the output of `portcheck version --json`.
- **Security issues:** follow [SECURITY.md](SECURITY.md); please don't file them publicly.

portcheck is maintained by volunteers; there is no guaranteed response time.
